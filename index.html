ElevenLabs API key
Inside LUNA the key is kept in your system keychain, never in the Add On's files.
How to get your API key
  1. Sign in to ElevenLabs, or create an account at elevenlabs.io. A free plan is available.
  2. Open the API Keys page of your dashboard:
  3. On the API keys tab, click Create Key and name it, such as LUNA.
  4. Restrictions are optional. If you limit the key, allow the features you'll use (Text to Speech, Sound Effects, Music, Voice Changer, Voices) and reading Models and User info.
  5. Copy the key and keep it private: anyone with it can spend your credits.
  6. Come back and click Paste key. It checks and saves the key, then clears it from the clipboard.
